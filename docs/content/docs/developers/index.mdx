Account Demolisher is a Next.js application that closes Stellar accounts. The close runs in the
browser: the account audit, DeFi discovery, plan generation, simulation, the sign-time checks, and
signing all happen client-side, and the browser submits every transaction itself.

The server has four narrow jobs, and none of them involves a user's key.

## What runs where

| Runs in the browser                           | Runs on the server                                                |
| --------------------------------------------- | ----------------------------------------------------------------- |
| Reading the account from Horizon              | Minting, renewing and co-signing exchange forwards (the mediator) |
| Discovering DeFi positions on chain           | Holding multisig signing requests in memory (the signing relay)   |
| Generating the plan and simulating every step | Recording first-party usage metrics and verified closes           |
| Checking every step before it is signed       | Proxying the Soroswap aggregator API, which the app does not call |
| Signing through the wallet and submitting     |                                                                   |

Position discovery needs no server and no API key. Blend, Soroswap and Aquarius concentrated pools
are read directly from their contracts. Aquarius standard pools are read from the Aquarius REST API
and from an on-chain event scan, and the two results are combined.
