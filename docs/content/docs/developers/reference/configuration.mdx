title: Configuration
description: Every environment variable the app reads, with its scope, default, validation and effect.
---

Public variables (`NEXT_PUBLIC_*`) are inlined into the client bundle at **build time**, so a
change needs a rebuild. Server-only variables are read at **runtime**.

For local development, copy `.env.example` to `.env.local`. The Docker image takes the public
variables as build arguments and the server variables from its environment; see
[Self-hosting](/docs/developers/operations/self-hosting).

## Public

| Variable                               | Default                  | Effect                                                                                                                                                                                                    |
| -------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_STELLAR_NETWORK`          | `testnet`                | The starting network: `mainnet` or `testnet`. The header selector switches between them at runtime                                                                                                        |
| `NEXT_PUBLIC_DEPLOYMENT_MODE`          | `reference`              | `reference` runs the exchange mediator. `self-hosted` does not: a close that needs it (a registry exchange or a SEP-29 memo-required destination) is refused, leaving direct closes                       |
| `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` | unset                    | A Reown project id. When set, WalletConnect joins the wallet picker. When unset it is left out and the relay is never contacted                                                                           |
| `NEXT_PUBLIC_SITE_URL`                 | `https://demolisher.app` | The canonical origin for page metadata, the sitemap and `robots.txt`. A trailing slash is trimmed                                                                                                         |
| `NEXT_PUBLIC_SLIPPAGE_BPS`             | `100` (1%)               | Slippage tolerance in basis points for every market conversion in a close: the classic path-payment and pool-withdraw floors and the Soroban exit and swap floors. A whole number from 10 to 500          |
| `NEXT_PUBLIC_MIN_MARKET_OUT_STROOPS`   | `0`                      | A floor in stroops for a conversion's XLM output. A balance whose slippage-adjusted output is at or below it is not sold, and goes to its issuer or to the destination instead. A whole number, 0 or more |

### Validation

A blank value counts as unset for every public variable, because an unset Docker build argument
arrives as an empty string.

`NEXT_PUBLIC_STELLAR_NETWORK` and `NEXT_PUBLIC_DEPLOYMENT_MODE` only accept the values listed. Any
other value throws when the app reads its configuration:

```
Invalid public environment configuration: <detail>
```

`NEXT_PUBLIC_SLIPPAGE_BPS` and `NEXT_PUBLIC_MIN_MARKET_OUT_STROOPS` are checked when `next.config.ts`
loads, so a malformed or out-of-range value fails `next build` and `next dev` with a
`SlippageConfigError` naming the variable. Only unset or blank uses the default.

## Server-only

Never expose these to the client.

| Variable                  | Default                             | Effect                                                                                                                                                                                                       |
| ------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `MEDIATOR_SECRET`         | unset                               | A Stellar seed (`S...`) used only as the HMAC master that derives a fresh mediator keypair per exchange close and signs flow tokens. It is never an account: do not fund it. Needed only in `reference` mode |
| `MEDIATOR_ALLOWED_ORIGIN` | unset                               | Comma-separated origins allowed to call the mediator routes cross-origin. Unset means same-origin only                                                                                                       |
| `TRUSTED_PROXY_HOPS`      | `1`                                 | How many reverse proxies in front of the app append to `X-Forwarded-For`. The rate limiter keys on the entry that many places from the right. A whole number, at least 1                                     |
| `METRICS_ADMIN_TOKEN`     | unset                               | The bearer token for `GET /api/metrics`. Unset, or shorter than 16 characters, makes that read answer 503. Recording metrics does not need it                                                                |
| `METRICS_DB_DIR`          | `data/` under the working directory | Where the metrics store keeps `closes.jsonl` and `counters.json`. Must be writable. The Docker image sets `/app/data`                                                                                        |
| `SOROSWAP_API_URL`        | `https://api.soroswap.finance`      | The Soroswap aggregator base URL for the `/api/soroswap` proxy                                                                                                                                               |
| `SOROSWAP_API_KEY`        | unset                               | The aggregator API key the proxy adds. No code in the app calls the proxy: closes convert through the pinned Soroswap router on chain                                                                        |

### Validation

The server configuration module imports `server-only`, so importing it from a client bundle is a
build error. An empty string counts as unset.

- **`TRUSTED_PROXY_HOPS`** is checked when the server starts (`src/instrumentation.ts`). A value
  of `0` or anything that is not a whole number logs `refusing to start: <reason>` and exits. The
  app is supported only behind a reverse proxy.
- **`MEDIATOR_SECRET`** must start with `S` and be 56 characters, or be unset. The full ed25519
  seed check runs at first use. A bad value disables only the mediator routes, which answer
  `MEDIATOR_NOT_CONFIGURED` and log the reason with any seed redacted.
- **`SOROSWAP_API_URL`** must be a URL. A bad value disables only the Soroswap proxy, which answers
  `SOROSWAP_NOT_CONFIGURED`.

Each feature validates only its own variables, so a bad value for one never disables another.

## Build and runtime switches

| Variable   | Effect                                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV` | Set by Next. Selects the development or production CSP, turns HSTS on in production, and in development lets `localhost:3000`, `:3001` and `:3002` call the mediator routes cross-origin |

The only supported target is the server build (`next build`, then `next start`). The API routes
and the per-request CSP need a running server, so there is no static export.

## Endpoints are not environment variables

Horizon and Soroban RPC endpoints are pinned per network in `src/lib/config/networks.ts`. Editing
that file is how you point the app at other providers, and the CSP follows it. See
[Networks and endpoints](/docs/developers/reference/networks).

## Outbound connections from the server

The server itself contacts:

- Horizon, from `/api/plan` (the account's signers and sequence), `/api/mediator/reissue` (whether
  the mediator exists) and `/api/metrics` (close verification).
- The Soroswap aggregator, only when something calls `/api/soroswap`. The proxy resolves that host
  through the public resolvers 1.1.1.1 and 8.8.8.8, to avoid category-based DNS blocking. Allow
  that if your egress is locked down.
